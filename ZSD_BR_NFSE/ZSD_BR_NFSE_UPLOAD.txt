* Functional description                                              *
* NFS-e upload - user program (transaction ZNFSE).                    *
*   1 - Reads the NFS-e issuing workbook (sheet "Emissão NF -         *
*       Ductor"), stores file and lines in ZSD_BR_NFSE_FILE / _DATA,  *
*       validates every line, checks duplicates and creates one Nota  *
*       Fiscal Writer per valid line (BAPI_J_1B_NF_CREATEFROMDATA).   *
*       RPS of the spreadsheet = J_1BNFDOC-NFNUM.                     *
*   2 - Execution log (ALV with traffic lights, link to J1B3N).       *
*   3 - Output file: CSV in the layout of the city portal export,     *
*       for NFs whose NFS-e was authorized (J1BNFE).                  *
* Parameters: table ZSD_BR_NFSE_PARM (admin program ZNFSE_ADM).       *
* Functional specification: ZSD_BR_NFSE_Design.md (repository TUV).   *
*---------------------------------------------------------------------*
* Authorization logic                                                 *
* Same check as the standard transaction J1B1N:                       *
*   option 1     - F_BKPF_BUK (BUKRS, ACTVT 01) + S_TCODE J1B1N       *
*   options 2, 3 - F_BKPF_BUK (BUKRS, ACTVT 03) per company code      *
*   J1B3N link   - CALL TRANSACTION ... WITH AUTHORITY-CHECK          *
* The issue date cannot be changed here (always today).               *
